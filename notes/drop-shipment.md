# Drop Shipment 直接出貨營運模式與合作機制

## 重點摘要
本篇介紹 Drop Shipment 直接出貨模式，由代工廠直發配送，賣方賺取差額並降低庫存與物流負擔，並彙整合作前對出貨可靠性、品質與系統對接的確認要點。

## 核心概念
Drop Shipment 為直接出貨模式。其運作流程為：顧客下單 → 賣方通知代工廠（商品與收件資料）→ 代工廠直接出貨給顧客 → 賣方賺取零售價與代工成本價之間的差額。

## 講義提到的優勢
Drop Shipment 能降低大量備貨、倉儲與物流負擔；賣方可以專注品牌、行銷與顧客服務，也更容易測試新產品。

## 合作前需確認要點
建立直接出貨合作前，需確認以下項目：
- 出貨速度與可靠性
- 品質是否穩定
- 退換貨流程
- 訂單系統對接
- 客製化包裝與品牌形象
